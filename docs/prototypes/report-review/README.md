# 报告页原型与 Prompt（待确认）

本轮只回答一个问题：用户能否在整场六维报告里方便地理解分数、查看亮点与不足，并通过原文核查判断，而不在报告页重答？

## 范围与来源

- [用户提供] 点击维度或评分细则，展示该维度标准、回答亮点和不足；未来使用模型进行审查。
- [用户提供] 移除报告页的全部重答逻辑，不满意时返回此前作答部分修改。
- [既定规则] 整场评分，不逐题评分；权重 23、27、17、13、13、7；用户确认不补答的维度默认 60 分；重新评估由用户手动发起，替换旧报告。
- [合理假设] 生成报告时一次生成六维分析，点击查看只读取已有结果，不反复调用模型。
- [原型样例] 人物、回答、评分和分析均为手工示例，不能作为用户真实表现或模型效果证明。

## 打开

在项目目录运行 `npm run prototype:report-review`，打开 `http://localhost:3002/`。也可以直接打开同目录 `index.html`，但独立文件模式下查看 Prompt 应打开旁边的 `prompt.md` 文件。

原型预览服务完全独立于正式应用，不读取账户、录音、密钥或练习记录，不提供 API，也不调用真实模型。运行端口可通过 `REPORT_PREVIEW_PORT` 修改。

## 三种布局

- A：左右分栏（推荐）。左侧六维评分，右侧当前维度的回答分析／评分细则。
- B：逐项展开。点击某一维度，在该行下方展开完整说明。
- C：列表与详情抽屉。评分列表保持紧凑，点击查看分析后打开右侧抽屉。

用底部箭头或键盘左右键切换；`?variant=A/B/C` 可分享对应布局。打开对话框或操作表单时不截获左右键。

## 点击检查

1. 点击专业能力维度，查看评分理由、亮点、不足。
2. 点击评分细则，查看该维度考察点与评分档位。
3. 点击查看完整回答，打开只读报告快照；从原文可进入返回该题作答的出口演示。
4. 点击学习成长潜力，查看未补答默认 60 分的说明，不虚构亮点或不足。
5. 切换演示状态到分析失败：该维度显示“—”，总分不计算，不显示为 0 分；重试仅为本地模拟。
6. 切换到回答已修改：旧报告继续可看，明确待重新评估；重新评估按钮仅演示状态替换。

- 通过：A/B/C 的维度选择、回答分析与评分细则切换、引用原文打开关闭、默认分与失败状态。
- 通过：原型中不存在答案输入框、录音播放器或上传控件；报告页没有重答、框架生成或采用答案动作。
- 通过：390px、320px 页面无横向溢出，桌面与手机已截图查看，无浏览器脚本错误。
- 未接入：实际模型分析、真实作答跳转、正式报告保存和版本校验。这些在用户确认后另行实施。
