# 好好找练习基础实施计划

**目标**：交付支持非固定题量、持久化作答和可选邀请制隔离的首个练习版本。

**架构**：复用 TypeScript HTTP 服务、SQLite 会话和本地音频存储。通过管理员初始化开启账户模式，现有本机演示数据保留在原数据库。生产化模型和完整工作台接入属于后续里程碑。

**规格**：《好好找 PRD 0.1》的模拟练习和账户权限条目。

- [x] 泛化题单、录音、作答与报告中的题号，保持已有两题流程及其录音兼容。
- [x] 通过同一页面增加逐题移动和文字保存，允许提前结束并留待复盘。
- [x] 添加账户存储、一次性邀请、登录会话及练习归属检查。账户模式下未分配的旧练习保持隔离。
- [x] 验证原有录音路径、三道题与文字保存、邀请重复兑换和跨账户读写。
